ラットプルダウンが背中に効かない原因の多くは、「腕で引いている」「肩がすくんでいる」「重すぎて反動を使っている」の 3 つです。引く前に肩を下げ、バーではなく肘を下ろす意識に変え、重量を一段軽くすると、背中で引く感覚をつかみやすくなります。この記事では、症状から原因を探せる早見表と、セッティング、動作の手順、直し方を順番に整理します。

## 症状から探す：効かない原因と直し方の早見表

| 症状                           | 主な原因                       | 直し方                                             |
| ------------------------------ | ------------------------------ | -------------------------------------------------- |
| 腕（力こぶ・前腕）ばかり疲れる | 手でバーを引き寄せている       | 肘を下ろす意識に変え、握りは軽めにする             |
| 首や肩の上がつらい             | 肩がすくんだまま引いている     | 引き始める前に肩を下げる                           |
| 上体が大きく後ろに倒れる       | 重量が重すぎて反動を使っている | 重量を下げ、上体の傾きは少しにとどめる             |
| 回数はこなせるのに何も感じない | 戻す動作が速く、力が抜けている | 2〜3 秒かけてゆっくり戻す                          |
| 引くたびにお尻が浮く           | 太ももパッドが合っていない     | パッドを太ももに密着する高さにする                 |
| 動きが小さく、腕が曲がったまま | 重すぎて可動域が狭い           | 上で腕をほぼ伸ばし、下は胸の上まで引ける重さにする |

複数当てはまる場合は、まず重量を下げてから他の項目を直すと、修正しやすくなります。

## セッティング：座る前に確認する 3 つ

1. **太ももパッドの高さ**：座ったとき、太ももがパッドで軽く押さえられ、引いても体が浮かない高さにします。すき間が大きいと、引くたびに体ごと持ち上がって力が逃げます。
2. **握る位置**：一般的には肩幅より少し広め（こぶし 1〜2 個分外側）が目安です。広すぎると動きが小さくなり、狭すぎると腕が主役になりやすくなります。
3. **重量**：フォームを崩さずに 10 回前後できる重さが目安です。最初は「軽すぎるかも」と感じるくらいから始め、背中に効く感覚がつかめてから上げていきましょう。

## 動作の手順：1 回の流れを 6 ステップで

1. バーを握り、太ももをパッドの下に入れて座る。腕はまっすぐ上に伸びた状態にする。
2. 胸を軽く張り、上体をほんの少しだけ後ろへ傾ける。
3. **腕を曲げる前に、肩を耳から遠ざけるように下げる。** 背中の下のほうに軽く力が入る感覚があれば OK です。
4. 肘を脇腹の横、やや後ろへ下ろすように引き、バーを鎖骨から胸の上あたりまで近づける。
5. 下で一瞬止め、背中が縮んでいるのを感じる。
6. 2〜3 秒かけてゆっくり戻し、上で腕をほぼ伸ばしきる。肩が自然に少し上がるところまで戻して構いません。

回数とセット数は、一般的に 10〜12 回を 3 セット、セット間の休憩は 1〜2 分程度が目安です。体力や目的に合わせて調整してください。

## フォームのポイント：どこに意識を置くか

| 意識する場所 | ポイント                                           |
| ------------ | -------------------------------------------------- |
| 手           | フックのように引っかけるだけ。強く握りしめない     |
| 肘           | 「バーを引く」ではなく「肘を脇腹へ下ろす」と考える |
| 肩           | 引いている間はずっと下げたまま。耳に近づけない     |
| 胸           | バーを迎えにいくように軽く張る                     |
| 上体         | 傾けるのは少しだけ。引くたびに前後に揺らさない     |

## よくある間違いと直し方

### 腕で引いてしまう

バーを手で引き寄せる意識だと、力こぶや前腕が先に疲れます。

- 握りを軽くする。親指を他の指と同じ側にそろえる握り方（サムレスグリップ）を試すのも一つの方法です。バーが滑りそうなら無理に使わないでください
- 「手はバーに引っかけているだけ、動かすのは肘」と考える
- 背中の日は、ダンベルカールなど腕の種目を先にやらない

### 肩がすくむ

肩が上がったまま引くと、首まわりや肩の上が主に働いてしまいます。

- 1 回ごとに「肩を下げる → 肘を下ろす」の順番を守る
- 練習として、軽い重量で肘を伸ばしたまま肩を下げる・戻すだけの動きを数回行い、肩を下げる感覚を確かめる

### 重すぎて反動を使う

上体を大きく倒して勢いで引くと、背中より反動で動かすことになり、腰にも負担がかかりやすくなります。

- 上体の傾きは、引き始めから終わりまでほぼ一定に保つ
- 最後の数回でフォームが崩れるなら、その重さは今の自分には重すぎるサインと考えて一段下げる

### 戻す動作が速い

下ろした直後に力を抜くと、背中に負荷がかかる時間が短くなります。

- 戻しは 2〜3 秒を目安に、バーに引っ張られないようコントロールする
- 戻したときにウエイトが音を立ててぶつからないようにする

### バーを首の後ろに引く

首の後ろへ下ろすやり方は、肩の柔軟性によっては肩や首に負担がかかりやすくなります。初心者は、胸の前に引く方法から始めるのが無難です。

動作中に肩や腰に痛みが出たら、その場で中止してください。肩や腰に持病や痛みがある人は、始める前に医師に相談しましょう。

## 効く感覚をつかむための工夫

- **軽い重量で下で 2 秒止める**：背中が縮む感覚を確かめやすくなります
- **背中の種目を続けて行う**：ラットプルダウンの後にシーテッドロウ（後ろへ引く動き）を行うと、背中を別の方向から使えます。懸垂に近い動きを練習したいなら、アシストチンニングも選択肢です
- **1 回でつかめなくてもよいと考える**：感覚は数回のトレーニングで少しずつつかめていくものです。重量より、1 回ごとの手順を守ることを優先しましょう

## まとめ

- 効かない原因の多くは「腕で引く」「肩がすくむ」「重すぎて反動を使う」の 3 つ
- 引く前に肩を下げ、バーではなく肘を脇腹へ下ろす
- 太ももパッドを密着させ、握りは肩幅より少し広めが目安
- 戻しは 2〜3 秒かけてコントロールする
- 迷ったら重量を一段下げてからフォームを直す
- 痛みが出たら中止し、持病や痛みがある人は医師に相談する
