器具なしで始めるなら、**スクワット、膝つき腕立て伏せ、ヒップリフト、リバースランジ、プランクの5種目を「40秒動いて20秒休む」で2周**するのがおすすめです。これで約10分になり、下半身・上半身・体幹をひと通り動かせます。ジャンプを入れないので音が出にくく、ヨガマット1枚分のスペースがあればできます。

ジムに行けない日にこのメニューをこなせば、運動しない日が続いて習慣が途切れるのを防ぎやすくなります。以下で、メニューの進め方、各種目のやり方、音とスペースへの配慮、ジム通いとの組み合わせ方を順に説明します。

## 10分メニューの全体像

| 順番 | 種目             | 主に使う部位   | 時間           |
| ---- | ---------------- | -------------- | -------------- |
| 1    | スクワット       | 太もも・お尻   | 40秒＋休憩20秒 |
| 2    | 膝つき腕立て伏せ | 胸・腕・肩     | 40秒＋休憩20秒 |
| 3    | ヒップリフト     | お尻・太もも裏 | 40秒＋休憩20秒 |
| 4    | リバースランジ   | 太もも・お尻   | 40秒＋休憩20秒 |
| 5    | プランク         | 体幹           | 40秒＋休憩20秒 |

1周で約5分、2周で約10分です。進め方は次のとおりです。

1. スマートフォンのタイマーを40秒と20秒のくり返しで設定する
2. 1周目はゆっくり、浅めの動きで体を温める
3. 2周目はフォームを保てる範囲でしっかり動く
4. 終わったら太もも、お尻、胸を軽く伸ばす

下半身と上半身・体幹を交互に並べているので、同じ部位が続けて疲れにくく、初心者でも10分を通しやすい構成です。回数は数えなくて構いません。40秒の中で、フォームが崩れない速さで続けることを優先してください。

## 5種目のやり方とフォームのポイント

### 1. スクワット

1. 足を肩幅に開き、つま先をやや外に向ける
2. 椅子に座るようにお尻を後ろへ引きながら、2秒ほどかけてしゃがむ
3. 太ももが床と平行になるくらいを目安に、無理のない深さで止める
4. 足裏全体で床を押して立ち上がる

膝とつま先の向きをそろえ、膝が内側に入らないようにします。

### 2. 膝つき腕立て伏せ

1. 床に膝をつき、手を肩幅より少し広めにつく
2. 膝から頭までが一直線になる姿勢を作る
3. 肘を曲げて胸を床に近づけ、床を押して戻る

お尻が上がったり腰が落ちたりしたら、一度止まって姿勢を作り直します。手首に痛みが出る場合は無理をせず中止してください。

### 3. ヒップリフト

1. 仰向けになり、膝を立てて足を腰幅に開く
2. かかとで床を押し、お尻を持ち上げる
3. 肩から膝までが一直線になったところで1秒止め、ゆっくり下ろす

腰を反らせて持ち上げるのではなく、お尻を締めて上げる意識を持ちます。

### 4. リバースランジ

1. 足を腰幅にして立つ
2. 片足を大きく後ろへ引き、両膝を曲げて腰を落とす
3. 前足のかかとで床を押して元の位置に戻る
4. 左右交互にくり返す

前に踏み出すランジより着地の衝撃が小さく、音も出にくいのが宅トレ向きの理由です。ふらつく場合は壁や椅子に手を添えて構いません。

### 5. プランク

1. うつ伏せから、肘を肩の真下について体を支える
2. 頭からかかとまでを一直線に保つ
3. 呼吸を止めずに40秒キープする

腰が反ったり落ちたりすると、腰に負担がかかりやすくなります。40秒続かなければ途中で膝をついて休み、また姿勢を戻せば大丈夫です。

膝や腰に痛みが出る種目は、その日は外して別の種目に置き換えてください。持病やけががある人は、始める前に医師に相談しましょう。

## きついとき・物足りないときの調整

同じメニューでも、やり方を少し変えるだけで強度を調整できます。

| 種目             | きついときの軽い版             | 物足りないときの強い版                   |
| ---------------- | ------------------------------ | ---------------------------------------- |
| スクワット       | 椅子に座って立つ動きをくり返す | 3秒かけてしゃがみ、下で1秒止める         |
| 膝つき腕立て伏せ | 壁や机に手をついて行う         | 膝を伸ばした通常の腕立て伏せ             |
| ヒップリフト     | 持ち上げる高さを小さくする     | 片脚を伸ばして片脚で行う                 |
| リバースランジ   | 壁に手を添え、浅く腰を落とす   | 下ろす動きを3秒かけてゆっくり行う        |
| プランク         | 膝をついて行う                 | 片脚を床から少し浮かせ、左右を入れ替える |

メニュー全体を強くしたいときは、3周に増やすか、休憩を20秒から15秒に縮めるのが手軽です。ダンベルがある人は、スクワットやリバースランジで両手に持つと負荷を上げられます。逆に疲れている日は1周だけでも構いません。

## 音とスペースへの配慮

集合住宅では、運動そのものより音や振動が気になって続かないことがあります。次の工夫で、夜でも取り組みやすくなります。

| 気になる点   | 対策                                                                |
| ------------ | ------------------------------------------------------------------- |
| 足音・着地音 | ジャンプする種目を入れない。しゃがむ・戻る動きをゆっくりにする      |
| 床への振動   | ヨガマットや厚手のラグを敷く                                        |
| 夜間・早朝   | ヒップリフトやプランクなど、床に近い種目の時間を長めにする          |
| 狭い部屋     | 両手を広げても家具に当たらない、ヨガマット1枚分ほどの場所を確保する |
| 足元の滑り   | 靴下は滑りやすいので、素足か室内用の運動靴で行う                    |

今回の5種目は、どれもその場で完結し、跳ばない動きだけで組んでいます。動作をゆっくり行うほど音は出にくくなり、筋肉にもしっかり効かせやすくなります。

## ジムに行けない日の代わりにするコツ

宅トレは、ジム通いの代わりというより、ジムに行けない日をつなぐ役割で考えると続けやすくなります。

- **行けない日のルールを先に決める**: 「ジムに行けなかった日は、帰宅して着替えたら10分だけやる」のように、時間と場所を決めておくと迷わずに始められます。
- **ジムとの部位の重なりに気をつける**: 前日にジムで脚をしっかり鍛えた場合は、翌日の宅トレは腕立て伏せやプランクを中心にします。筋肉痛が強い日は休むのも選択肢です。
- **10分は最低ラインと考える**: 時間があって余裕がある日は周を足し、疲れている日は1周で終える。ゼロの日を作らないことを優先します。
- **ジムの回数目標は控えめに設定する**: 一般的には週2〜3回の運動が目安とされます。ジムは無理なく通える回数にして、足りない分を宅トレで補うと、計画倒れになりにくくなります。
