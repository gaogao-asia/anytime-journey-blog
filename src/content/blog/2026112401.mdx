週3回ジムに通うなら、初心者は**全身を毎回鍛える (A・Bの2メニューを交互)**、慣れてきたら**上半身・下半身の2分割**、種目を増やしたい中級者は**プッシュ・プル・脚の3分割**が組みやすい選び方です。週3回という枠では、分割を細かくするほど1部位を鍛える回数が減ります。まずは「各部位を週に何回鍛えられるか」で選ぶのがコツです。

この記事では3パターンのメニュー例を、種目・回数とセット数の目安・順番つきで一覧にしました。

## 週3回の分割法は3パターン｜早見表で選ぶ

| パターン                | 向いている人                           | 各部位を鍛える頻度          | 1回の種目数の目安 |
| ----------------------- | -------------------------------------- | --------------------------- | ----------------- |
| 全身×3回 (A/B交互)      | 始めたばかり〜フォームを固めたい人     | 週3回                       | 5種目             |
| 上半身/下半身の2分割    | 全身メニューに慣れ、種目を増やしたい人 | 週1〜2回 (週ごとに入れ替え) | 6〜7種目          |
| プッシュ/プル/脚の3分割 | 中級者、1部位をじっくり鍛えたい人      | 週1回                       | 6種目             |

選ぶときの目安は次のとおりです。

- **迷ったら全身×3回**。同じ種目を週に何度も練習できるので、フォームが身につきやすくなります。
- **全身だと1回が長くなる、種目が物足りない**と感じたら2分割へ。
- **週3回をほぼ休まず通える**なら3分割。1回休むとその部位が2週間空くので、予定が崩れやすい人には不向きです。

### 3パターン共通のルール

1. ウォームアップとして、エアロバイクやトレッドミルで5分ほど軽く体を温める
2. 脚・胸・背中など、大きい筋肉を使う種目から始める
3. 肩・腕など小さい筋肉の種目を後に回す
4. 腹筋は筋トレの最後に行う
5. 有酸素運動を入れるなら、筋トレの後に10〜20分程度 (任意)

回数とセット数は、一般的には**10〜12回で「あと1〜2回できそう」な重さを2〜3セット、セット間の休憩は1〜2分**が目安です。体力や経験によって個人差があるので、最初は軽めから始めてください。

## パターン1：全身×3回 (A/Bを交互に回す)

### メニューA

| 順番 | 種目             | 回数×セット (目安) | ポイント               |
| ---- | ---------------- | ------------------ | ---------------------- |
| 1    | レッグプレス     | 10〜12回×3         | 膝を伸ばしきらない     |
| 2    | チェストプレス   | 10〜12回×3         | 肩をすくめず胸を張る   |
| 3    | ラットプルダウン | 10〜12回×3         | 腕でなく肘を下げる意識 |
| 4    | ショルダープレス | 10〜12回×2         | 腰を反らせすぎない     |
| 5    | プランク         | 30秒×2             | お尻を上げすぎない     |

### メニューB

| 順番 | 種目                   | 回数×セット (目安) | ポイント                 |
| ---- | ---------------------- | ------------------ | ------------------------ |
| 1    | スミスマシンスクワット | 8〜10回×3          | 軽い重さでフォーム優先   |
| 2    | ダンベルベンチプレス   | 10〜12回×3         | 下ろす動作をゆっくり     |
| 3    | シーテッドロウ         | 10〜12回×3         | 胸を張って肩甲骨を寄せる |
| 4    | レッグカール           | 10〜12回×2         | 反動を使わない           |
| 5    | クランチ               | 15回×2             | 首ではなくお腹で丸める   |

**回し方：** 1週目はA→B→A、2週目はB→A→B。こうすると2週間でA・Bを3回ずつ行えます。

スミスマシンスクワットは腰や膝に負担がかかりやすい種目です。違和感や痛みが出たら中止し、レッグプレスに置き換えてください。腰や膝に持病がある人は、始める前に医師に相談すると安心です。

## パターン3：プッシュ・プル・脚の3分割

プッシュは「押す」動き (胸・肩・腕の裏側)、プルは「引く」動き (背中・腕の表側) です。

| 4    | サイドレイズ                   | 12〜15回×3         |

**回し方：** プッシュ→脚→プルの順がおすすめです。プッシュとプルはどちらも肩や腕を使うので、間に脚の日を挟むと上半身の疲れが抜けやすくなります。バックエクステンションは腰を反らせすぎないよう、上体がまっすぐになる位置で止めてください。腰に痛みがある日は外しましょう。

## 曜日の組み方と、行けなかったときの調整

| 曜日の例   | 特徴                                  |
| ---------- | ------------------------------------- |
| 月・水・金 | 毎回1日空くので、全身×3回と相性がよい |
| 火・木・土 | 平日2回+週末1回で予定を立てやすい     |
| 水・土・日 | 土日が連続するので、2分割か3分割向き  |

同じ部位は、一般的には48時間程度空けるのが目安です。全身メニューを2日連続で行うのは避け、連日になるなら分割法を選んでください。

行けない日が出たときは、次の手順で調整します。

1. 曜日ではなく**メニューの順番**で回す (水曜に行けなければ、水曜の予定を木曜に回す)
2. 週3回が難しい週は、全身メニューを1〜2回行って全身に刺激を入れる
3. 翌週は前の週の続きから再開する

順番で回すには、前回どのメニューをやったかを覚えておく必要があります。

## よくある間違いと直し方

| よくある間違い                | 起きやすいこと                   | 直し方                                                                   |
| ----------------------------- | -------------------------------- | ------------------------------------------------------------------------ |
| 週3回なのに4〜5分割を真似する | 各部位が月に数回しか鍛えられない | 週3回なら3分割までにとどめる                                             |
| 毎回同じ重さ・回数のまま      | 刺激に慣れて変化を感じにくくなる | 目標回数が楽にこなせたら、重さを少しだけ上げる                           |
| 腕や腹筋から始める            | 疲れて大きい種目で力が出ない     | 大きい筋肉→小さい筋肉→腹筋の順にする                                     |
| 全身メニューを連日行う        | 疲れが抜けずフォームが崩れやすい | 間に1日休みを入れる                                                      |
| 痛みを我慢して続ける          | ケガにつながるおそれがある       | すぐに中止し、重さを下げるか種目を替える。痛みが続くときは医師に相談する |

## まとめ

- 週3回の分割法は、**全身×3回 → 上半身/下半身 → プッシュ/プル/脚**の順に難易度が上がる
- 迷ったら全身A/Bを交互に回し、慣れて種目を増やしたくなったら分割する
- 順番は大きい筋肉→小さい筋肉→腹筋→有酸素。回数は10〜12回×2〜3セット、休憩1〜2分が目安
- 曜日ではなくメニューの順番で回すと、休んだ週でも崩れにくい
- 痛みが出たら無理をせず中止する
