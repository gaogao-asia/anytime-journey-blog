チェストプレスのシートは、**グリップを握ったときに手が胸の真ん中からやや下に来る高さ**が目安です。手が肩と同じか、それより高い位置にあると、胸より肩の前側に負担が寄りやすくなります。押し始める前に、横から見て「手・ひじ・肩」の位置関係を確かめましょう。それだけで、胸に効く感覚をつかみやすくなります。

## まず結論：シートの高さの目安

座ってグリップを握った状態で、次の4点を確認します。

| チェック項目   | 目安                                     |
| -------------- | ---------------------------------------- |
| グリップの高さ | 胸の真ん中(乳頭の高さ付近)からやや下     |
| ひじの高さ     | 肩よりやや下                             |
| 脇の開き       | 真横まで張らず、少し閉じて斜め下に向ける |
| 前腕の向き     | 押す方向とほぼ一直線                     |

鏡が横にあれば、横向きに座って見るとわかりやすいです。鏡がない場合は、グリップを握ったまま視線を下げてみてください。手が鎖骨のあたりに見えたら高すぎ、みぞおちより下に見えたら低すぎ、と判断できます。

### 高さがずれたときに起きやすいこと

| 状態                                       | 起きやすいこと                                               | 直し方                             |
| ------------------------------------------ | ------------------------------------------------------------ | ---------------------------------- |
| シートが低い(グリップが肩の高さ以上)       | 肩がすくむ。肩の前側ばかり疲れて、胸に効いている感覚が薄い   | シートを1〜2段上げる               |
| シートが高い(グリップがみぞおち付近より下) | 押す方向が下向きになり、手首が反りやすい。腕の力に頼りやすい | シートを1〜2段下げる               |
| ちょうどよい                               | 胸の張りを感じながら、まっすぐ前に押せる                     | 番号を控えて、次回も同じ設定にする |

体格によって合う高さは変わります。**前に使った人の設定のまま座らない**ことが、いちばん簡単で効果的な対策です。

## 動作前のセッティング手順

1. **重さを軽めにする**:最初は、余裕を持って15回ほどできる重さから始めます。
2. **シートの高さを合わせる**:シート横のレバーやピンで調整します。座ってグリップを握り、上の表の位置になっているか確認します。
3. **開始位置を合わせる**:機種によっては、背もたれの前後位置や、グリップの開始位置を変えるレバーがあります。グリップを握ったときに手が胸より少し前にあり、肩が後ろへ引っ張られすぎない位置にします。足で踏んでグリップを前に出すペダルが付いた機種もあります。
4. **グリップを選ぶ**:縦向き(手のひらが向かい合う)と横向きの2種類がある機種では、肩に違和感が出にくいほうを選びます。迷ったら縦向きから試すと、脇を締めやすいです。
5. **座り方を整える**:お尻を背もたれの奥まで入れ、背中を背もたれにつけ、足裏を床にしっかりつけます。

## 動作の手順

1. 肩甲骨を軽く寄せて下げ、胸を少し張る
2. 息を吐きながら、1〜2秒かけて前に押す
3. ひじが伸びきる手前で止める
4. 息を吸いながら、2〜3秒かけてゆっくり戻す
5. プレート同士がつく手前で切り返し、次の回に入る

回数や重さは、一般的な目安として次のように考えるとよいでしょう。

| 項目     | 目安                                                 |
| -------- | ---------------------------------------------------- |
| 回数     | 10〜15回                                             |
| セット数 | 2〜3セット                                           |
| 休憩     | セット間1〜2分                                       |
| 重さ     | 最後の2〜3回がきついが、フォームを崩さずにできる程度 |

体力や経験によって合う設定は変わります。フォームが崩れる重さまで無理に上げないでください。

## フォームのポイント

- **肩をすくめない**:押すときに肩が耳に近づいたら、重さか高さが合っていないサインです。
- **背中を背もたれから離さない**:押す瞬間に上体が前に出ると、胸への負荷が抜けやすくなります。
- **手首をまっすぐ保つ**:手のひらの付け根でグリップを押す意識を持つと、手首が反りにくくなります。
- **ひじをロックしない**:伸びきる手前で止めると、胸に負荷がかかり続けます。
- **戻しを丁寧に**:戻す動作も胸を使う時間です。重りに引っ張られないようにコントロールします。

## よくある間違いと直し方

| よくある間違い                       | 原因として多いもの                             | 直し方                                             |
| ------------------------------------ | ---------------------------------------------- | -------------------------------------------------- |
| 肩がすくむ、肩の前側ばかり疲れる     | シートが低い、重すぎる                         | シートを上げ、重さを下げる。肩甲骨を下げてから押す |
| 腰が大きく反る、お尻が浮く           | 重すぎる                                       | 重さを下げ、足裏を床につけ直す                     |
| ひじを伸ばしきり、戻すときに音が鳴る | 勢いで動かしている                             | 伸びきる手前で止め、戻しを2〜3秒かける             |
| 手首が反って痛む                     | シートが高い、握り方が浅い                     | シートを下げ、手のひらの付け根で押す               |
| 胸より腕が先に疲れる                 | 脇が開きすぎ、または閉じすぎ。胸を張れていない | 脇を少し閉じて斜め下に向け、胸を張ってから押す     |
| 戻したときに肩が後ろへ引っ張られる   | 開始位置が深すぎる                             | 背もたれやグリップの開始位置を前に調整する         |

高さや開始位置を直しても肩の前側に痛みが出る場合は、その日は中止してください。痛みが続く人や、肩に持病がある人は、続ける前に医師に相談しましょう。

## 設定を記録して、次回の調整を短くする

ちょうどよい高さが見つかったら、シートの番号とグリップの開始位置をスマホのメモなどに控えておきましょう。次回は座る前に番号を合わせるだけで済み、毎回のフォームも安定しやすくなります。あわせて重さと回数も記録しておくと、少しずつ重くしていくときの判断材料になります。

## まとめ

- シートの高さは、グリップが胸の真ん中からやや下に来る位置が目安
- 手が肩の高さ以上なら低すぎ、みぞおち付近より下なら高すぎ
- 前の人の設定のまま使わず、座るたびに高さと開始位置を確認する
- 肩甲骨を下げて胸を張り、1〜2秒で押して2〜3秒で戻す
- 合う設定が見つかったら、番号を控えて次回も同じ条件で始める
