週2回のジム通いなら、毎回「全身」を鍛えるメニューが組みやすく、続けやすい形です。マシン中心に5〜6種目を選び、1種目10〜15回×2〜3セットを目安に、脚・胸・背中などの大きな筋肉から順に行います。種目を少し入れ替えたAとBの2パターンを交互に回せば、毎回迷わずに全身をまんべんなく動かせます。

## なぜ週2回なら全身メニューなのか

部位ごとに日を分ける「分割法」は、週に何度も通える人向けの組み方です。週2回で分割すると、それぞれの部位を鍛えるのが週1回程度になりがちです。毎回全身を行えば、各部位を週2回ずつ動かせます。

| 組み方                         | 週2回の場合               | 初心者への向き           |
| ------------------------------ | ------------------------- | ------------------------ |
| 全身法（毎回全身）             | 各部位を週2回動かせる     | 種目が少なく覚えやすい   |
| 分割法（部位ごとに日を分ける） | 各部位が週1回になりやすい | 通う回数が増えてから検討 |

### 基本ルールの目安

一般的に初心者向けとされる目安をまとめると、次のようになります。体力や体格によって合う量は変わるので、きつすぎると感じたら少なめから始めてください。

| 項目           | 目安                                      |
| -------------- | ----------------------------------------- |
| 頻度           | 週2回、間を2〜3日あける（例：月曜と木曜） |
| 種目数         | 筋トレ5〜6種目＋前後の有酸素運動          |
| 回数           | 10〜15回をフォームを崩さずにできる重さ    |
| セット数       | 1種目2〜3セット                           |
| セット間の休憩 | 1〜2分                                    |
| 所要時間       | 全体で45〜60分程度                        |

## 週2回・全身メニュー例（AとBを交互に）

1回目はA、2回目はB、次の週はまたA、という順で回します。どちらも大きな筋肉から小さな筋肉へ進むように並べ、腹筋・体幹は最後に置いています。

### メニューA（マシン中心）

| 順番   | 種目                         | 主な部位       | 回数×セット（目安） |
| ------ | ---------------------------- | -------------- | ------------------- |
| 始め   | エアロバイク                 | ウォームアップ | 5〜10分             |
| 1      | レッグプレス                 | 太もも・お尻   | 10〜15回×3          |
| 2      | チェストプレス               | 胸             | 10〜15回×3          |
| 3      | ラットプルダウン             | 背中           | 10〜15回×3          |
| 4      | ショルダープレス             | 肩             | 10〜15回×2          |
| 5      | レッグカール                 | 太もも裏       | 10〜15回×2          |
| 6      | プランク                     | 体幹           | 20〜30秒×2          |
| 終わり | ウォーキング（トレッドミル） | クールダウン   | 10分程度            |

### メニューB（種目を少し入れ替える）

| 順番   | 種目                         | 主な部位       | 回数×セット（目安） |
| ------ | ---------------------------- | -------------- | ------------------- |
| 始め   | ウォーキング（トレッドミル） | ウォームアップ | 5〜10分             |
| 1      | スミスマシンスクワット       | 太もも・お尻   | 10〜15回×3          |
| 2      | シーテッドロウ               | 背中           | 10〜15回×3          |
| 3      | プッシュアップ               | 胸             | できる回数×3        |
| 4      | サイドレイズ                 | 肩             | 12〜15回×2          |
| 5      | レッグエクステンション       | 太もも前       | 10〜15回×2          |
| 6      | クランチ                     | お腹           | 10〜15回×2          |
| 終わり | エアロバイク                 | クールダウン   | 10分程度            |

- スミスマシンスクワットは、フォームに自信がないうちや、膝・腰に不安があるときはレッグプレスに置き換えて構いません。
- プッシュアップがきつい場合は、膝をついて行うか、チェストプレスに置き換えます。
- サイドレイズは軽いダンベルで十分です。肩をすくめず、腕を肩の高さまで上げるのが目安です。

### マシンが空いていないときの置き換え表

| 部位 | 第一候補         | 置き換え候補                                       |
| ---- | ---------------- | -------------------------------------------------- |
| 脚   | レッグプレス     | スミスマシンスクワット、レッグエクステンション     |
| 胸   | チェストプレス   | ダンベルベンチプレス、ペックフライ、プッシュアップ |
| 背中 | ラットプルダウン | シーテッドロウ、アシストチンニング                 |
| 肩   | ショルダープレス | サイドレイズ                                       |
| 体幹 | プランク         | クランチ、アブドミナルマシン                       |

同じ部位の種目に入れ替えれば、順番はそのままで問題ありません。

## 1回のトレーニングの流れ

1. 有酸素マシンで5〜10分ウォームアップする。軽く体が温まる程度で十分です。
2. 各種目の最初に、軽い重さで10回ほど練習セットを行い、動きと重さを確かめる。
3. 本番のセットに入る。セット間は1〜2分休む。
4. 表の順番どおりに種目を進める。息が上がっているときは休憩を少し長めにとる。
5. 最後に体幹の種目を行い、有酸素運動とストレッチでクールダウンする。

## 重さの決め方と増やし方

1. 初回は「軽すぎるかな」と思うくらいの重さから始める。
2. 15回できてまだ余裕があれば、次のセットで1段階上げる。
3. 10回に届かない、または途中でフォームが崩れるなら1段階下げる。
4. 「最後の2〜3回がきついが、フォームは保てる」重さが合っている目安。
5. すべてのセットで15回できるようになったら、次回から1段階上げる。

関節に痛みが出たときはその種目を中止し、無理に続けないでください。持病がある人や、もともと腰や膝に痛みがある人は、始める前に医師に相談すると安心です。

前回の重さと回数をメモしておくと、上げるか据え置くかをその場で判断しやすくなります。

## よくある間違いと直し方

| よくある間違い           | 起こりやすいこと                         | 直し方                                     |
| ------------------------ | ---------------------------------------- | ------------------------------------------ |
| 最初から重い重さを選ぶ   | フォームが崩れ、関節に負担がかかりやすい | 15回できる重さから始める                   |
| 反動をつけて動かす       | 狙った筋肉に効きにくい                   | 2秒で上げて2秒で下ろすくらいの速さにする   |
| 腕や腹筋から始める       | 後半の脚や背中で力が出にくい             | 大きな筋肉から順に行う                     |
| 休憩がばらばら           | 疲れ方が日によって変わり、比べにくい     | スマホのタイマーで1〜2分を測る             |
| 毎回メニューを変える     | 重さが伸びているかわからない             | AとBを数週間は固定する                     |
| マシン待ちで時間が延びる | 集中が切れ、疲れが残る                   | 置き換え表を使うか、空いている時間帯に行く |

## 慣れてきたらこう変える（レベル別ステップ）

| 段階      | 目安                   | 変えること                                                              |
| --------- | ---------------------- | ----------------------------------------------------------------------- |
| ステップ1 | 始めて最初の数週間     | AとBをそのまま行い、フォームと重さ選びに集中する                        |
| ステップ2 | 全種目を迷わずこなせる | セット数を3にそろえ、重さを少しずつ上げる                               |
| ステップ3 | 時間と体力に余裕がある | ダンベルカールやトライセプスプッシュダウン、カーフレイズを1種目追加する |
| ステップ4 | 週3回通えそう          | 週3回の全身法、または上半身と下半身に分ける組み方を検討する             |

次の段階に進むのは、疲れが翌々日まで残らず、フォームが安定してからで十分です。疲れが抜けない、どこかが痛むと感じたら、ひとつ前のステップに戻しましょう。

## まとめ

- 週2回なら、毎回全身を鍛える全身法が組みやすい
- マシン中心に5〜6種目、1種目10〜15回×2〜3セット、休憩1〜2分が目安
- 脚→胸・背中→肩→体幹の順に、大きな筋肉から進める
- AとBの2パターンを交互に回し、数週間は固定して重さの変化を見る
- 15回を全セットこなせたら1段階上げ、痛みが出たら中止する
