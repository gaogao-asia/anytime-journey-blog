筋トレの食事は、**トレーニングの2〜3時間前にふつうの食事をとり、間に合わないときは1時間前くらいまでに消化のよい糖質を少し。終わったら主食とタンパク質がそろった食事をとる**、という形を基本にすると組み立てやすくなります。前後の数十分を厳密に気にするより、空腹のまま始めないことと、トレーニング後の食事を抜かないことのほうが大切です。健太と美咲の会話で、具体的に見ていきましょう。

## 筋トレ前は「いつ」「何を」食べればいい？

<Talk who="kenta">

美咲さん、授業のあと夕方にジムへ行くんですけど、前に何か食べたほうがいいんですか？　お腹いっぱいだと動けないし、空腹だと力が出ない気がして。

</Talk>

<Talk who="misaki">

その感覚は大事だよ。筋トレ前の食事は「トレーニングまであと何時間あるか」で考えるとわかりやすいの。目安をまとめるとこんな感じ。

| トレーニングまでの時間 | 食べ方の目安         | 例                     |
| ---------------------- | -------------------- | ---------------------- |
| 2〜3時間前             | ふつうの量の食事     | 定食、おにぎりとおかず |
| 1時間前くらい          | 消化のよい糖質を軽く | おにぎり1個、バナナ    |
| 30分前以内             | ごく少量にとどめる   | ゼリー飲料、バナナ半分 |

</Talk>

<Talk who="kenta">

直前に唐揚げ弁当とかはダメですか？

</Talk>

<Talk who="misaki">

禁止ではないけど、直前はおすすめしにくいかな。脂質の多い料理や量の多い食事は消化に時間がかかりやすくて、動くとお腹が重く感じやすいの。食物繊維がとても多いものも同じ。どのくらい前なら平気かは個人差があるから、何度か試して自分に合うタイミングを見つけてね。

</Talk>

<Talk who="kenta">

逆に、何も食べずに行くのは？

</Talk>

<Talk who="misaki">

空腹がひどいと力が出にくかったり、ふらついたりしやすいよ。昼食から時間が空くなら、間食でおにぎりやバナナを入れておくのが手軽。もしトレーニング中にめまいや気分の悪さを感じたら、無理せず中止して休んでね。

</Talk>

## 筋トレ後はプロテインだけでいい？

<Talk who="kenta">

先輩に「終わったらすぐプロテインを飲まないと意味がない」って言われたんです。本当ですか？

</Talk>

<Talk who="misaki">

数分単位で焦る必要はないと思っていいよ。大事なのは、トレーニング後の食事をきちんととること。目安としては、終わってから1〜2時間くらいのうちに食事がとれると流れがいいね。プロテインは、食事まで時間が空くときのつなぎとして使うと便利だよ。

</Talk>

<Talk who="kenta">

食事は何を食べればいいですか？

</Talk>

<Talk who="misaki">

基本は次の3つをそろえること。

1. **主食**：ごはん、パン、麺などの糖質。トレーニングで使ったエネルギーを補う役割
2. **主菜**：肉、魚、卵、大豆製品などのタンパク質
3. **副菜**：野菜、きのこ、海藻など

体を絞りたくてごはんを抜く人もいるけど、トレーニングした日こそ主食は抜かないほうが、次のトレーニングにも力が入りやすいよ。

</Talk>

## タンパク質・糖質・脂質はどう考える？

<Talk who="kenta">

タンパク質・糖質・脂質って、結局どれをどれくらい気にすればいいんですか？

</Talk>

<Talk who="misaki">

細かい計算より、まずは毎食のお皿で考えてみて。

- **タンパク質**：毎食、手のひら1枚分くらいの肉・魚・卵・大豆製品を。1食あたり20g前後を目安にする考え方が一般的。夕食にまとめるより3食に分けるほうがとりやすい
- **糖質**：主なエネルギー源。毎食、主食を適量。減量中でもゼロにはしない
- **脂質**：体に必要な栄養素なのでゼロにはしない。揚げ物やこってりした料理が続くと量が増えやすいから、焼く・煮る・蒸すなど調理法で調整する

</Talk>

<Talk who="kenta">

タンパク質は多ければ多いほどいいんですよね？

</Talk>

<Talk who="misaki">

そうとは限らないよ。筋トレをする人の1日の量は、体重1kgあたり1〜2g程度の範囲で語られることが多いけど、あくまで目安。とりすぎると、ほかの栄養素が減ったり総カロリーが増えたりもする。腎臓などに持病がある人は、タンパク質を増やす前に医師に相談してね。

</Talk>

## コンビニと外食での選び方

<Talk who="kenta">

一人暮らしなので、コンビニと外食がほとんどなんです……。

</Talk>

<Talk who="misaki">

コンビニは組み合わせやすいから、むしろ便利だよ。場面ごとの例はこんな感じ。

| 場面                | 組み合わせ例                                   |
| ------------------- | ---------------------------------------------- |
| 筋トレ1時間前       | おにぎり1個、バナナ、ゼリー飲料のどれか        |
| 筋トレ後            | おにぎり＋サラダチキン＋カップのみそ汁         |
| 筋トレ後 (しっかり) | 幕の内などの弁当＋ゆで卵                       |
| 夜遅く              | 具だくさんのスープ＋おにぎり、温かいうどん＋卵 |

迷ったら、パッケージの栄養成分表示でタンパク質の量を見る習慣をつけるといいよ。

</Talk>

<Talk who="kenta">

外食だとどうですか？

</Talk>

<Talk who="misaki">

いちばん組み立てやすいのは定食。主食・主菜・副菜が最初からそろっているからね。ほかのお店でも、ひと品足すだけで整えやすくなるよ。

- **定食屋**：焼き魚定食、生姜焼き定食など
- **丼もの**：卵やサラダ、みそ汁を追加する
- **うどん・そば**：肉や卵がのったものを選ぶ
- **ファミレス**：グリルした肉や魚にライスを合わせる

ラーメンや揚げ物も、毎日でなければ気にしすぎなくて大丈夫。続けられることを優先しよう。

</Talk>

## 朝・夕方・夜、時間帯別の組み立て方

<Talk who="kenta">

朝にジムへ行く日もあるんですけど、そのときは？

</Talk>

<Talk who="misaki">

時間帯ごとの流れはこう考えるといいよ。

1. **朝トレの日**：前日の夕食をしっかりとり、起きたらバナナやおにぎりを軽く。終わってから朝食をとる
2. **夕方トレの日**：昼食をしっかり。夕方までに時間が空くなら間食を入れ、終わってから夕食
3. **夜トレの日**：夕方におにぎりなどで間食し、終わったら消化のよい夕食。寝る直前なら量は控えめに

</Talk>

## まとめ

- 筋トレ前は2〜3時間前にふつうの食事、間に合わなければ1時間前くらいまでに消化のよい糖質を軽く
- 直前は脂質の多い料理や量の多い食事を避け、空腹のまま始めない
- 筋トレ後は数分を焦るより、1〜2時間くらいのうちに主食とタンパク質のそろった食事を
- タンパク質は毎食に分けて、糖質と脂質もゼロにしない
- コンビニは組み合わせ、外食は定食か「ひと品追加」で整える
